# NetPause — экономия трафика для Windows

## ⬇️ [Скачать последнюю версию NetPause](https://github.com/ant1social77/NetPause-releases/releases/latest)

На открывшейся странице в разделе **Assets** нажмите на файл **NetPause-Setup-…exe** (около 62 МБ).

Скачивайте **именно файл `NetPause-Setup-…exe`**. Архивы «Source code (zip / tar.gz)» на странице релиза GitHub добавляет сам — программы в них нет, только этот текст.

## Как установить

1. Запустите скачанный `NetPause-Setup-…exe`.
2. Если появится синее окно **«Windows защитил ваш компьютер»** — нажмите **«Подробнее»**, затем **«Выполнить в любом случае»**. Это потому, что у установщика нет платной цифровой подписи.
3. Если браузер пишет, что файл «обычно не скачивают» или «может быть опасен», — выберите «Сохранить» / «Всё равно сохранить».
4. На вопрос Windows «Разрешить этому приложению вносить изменения?» нажмите **«Да»**. Нужна учётная запись с правами администратора.
5. В конце оставьте галочку «Открыть NetPause» — значок появится у часов, по нажатию на него открывается панель.

Интернет для установки не нужен. Нужна Windows 10 (версия 2004 или новее) или Windows 11, 64-битная.

## Если не запускается

После запуска NetPause не открывает обычное окно — он живёт **значком у часов** (стрелка «^» справа на панели задач). Нажмите на значок, чтобы открыть панель.

Если программа всё же не работает, она записывает причину в файл `C:\ProgramData\NetPause\crash.txt` (начиная с версии 1.0.1) — пришлите его автору.

## Для разработчиков: как собрать

Код программы лежит прямо в этом хранилище (C# .NET 8, WPF). Программа работает с правами администратора: учёт трафика идёт через ETW, блокировка — правилами файрвола Windows.

1. Установите [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) и [Inno Setup 6](https://jrsoftware.org/isdl.php).
2. Собрать и запустить для проверки: `dotnet build NetPause.csproj -c Release` (запускать от администратора).
3. Собрать установщик: `powershell -ExecutionPolicy Bypass -File build-installer.ps1` → `installer\NetPause-Setup-<версия>.exe`. Версия задаётся в `NetPause.csproj` (`<Version>`).

Данные пользователя в код не попадают: общие настройки лежат в `C:\ProgramData\NetPause`, логины трекеров — в `%LOCALAPPDATA%\NetPause` (в зашифрованном виде).
